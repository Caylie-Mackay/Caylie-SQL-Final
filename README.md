# Caylie-SQL-Final
Final project of my data technologies SQL course.

## Project Goals
My goals for this project were to discover the retailers and departments with the best bulk discount prices.
I also wanted to find what brands tend to be more expensive when compared to others and what brands offered the best discounts.

## Dataset Structure
To structure my dataset I split it into three tables. One containing all the retail store information, one containing the product information, and one final table containing all of the transaction information.
The transaction table connected to the product table using the sku number and connected to the store information using the transaction number.

## Findings
In the end I found that the top three retailers with the best discounts are 84 Lumber, Menards and Lowe's.

The brands with the best discount percentages are GE, LG, Milwaukee and Rust-Oleum.
Some brands that I found had a higher average price compared to all other brands were BOSCH, Ryobi and Samsung.

The department with the highest quantity of orders is flooring, this department also had the highest bulk discount percent at 14.16%.
This could be due to flooring being sold per piece at times.

## Fun Fact!
The store with the largest single order was 84 Lumber in New Rachel, MT, with $377,689 of product sold and a total discount of $75,537.80!
